# Whalefall Website Guide

This is the simple guide for opening the Whalefall website and updating the content.

## Website Links

When the site is fully deployed, there will be two main links:

- Public website: `https://your-whalefall-site.vercel.app`
- Editing dashboard: `https://your-whalefall-site.vercel.app/studio`

The exact website link may change if you connect a custom domain later.

## Preview Link While The Site Is Being Built

Right now, if the developer has the site running locally, it can be previewed here:

`http://127.0.0.1:3000`

This local preview only works on the computer that is running the website. It is not the final public website link.

## How To Edit The Website

1. Go to the editing dashboard:

   `https://your-whalefall-site.vercel.app/studio`

2. Log in with the Sanity account that has been invited to edit the Whalefall website.

3. Choose the section you want to update.

4. Make the change.

5. Click `Publish`.

Most changes should appear on the website within about a minute.

## What You Can Update

### Site Settings

Use this to update:

- Band name
- Contact email
- Guestbook link
- Social links

### Homepage Featured Content

Use this to choose what appears on the homepage:

- Featured release
- Recent shows
- Studio/media carousel images
- Recent blog posts
- Sketches and lyrics

### Releases

Use this to add or update:

- Release title
- Release date
- Description
- Cover image
- Bandcamp, Spotify, Apple Music, SoundCloud, and YouTube links

### Shows

Use this to add or update:

- Show title
- Date
- Location
- Set time
- Description
- Link to photos from the show

### Blog Posts

Use this for band updates, notes, announcements, tour journals, or longer posts.

For each post:

1. Add a title.
2. Click `Generate` next to the slug field.
3. Add the date, excerpt, body text, and images.
4. Click `Publish`.

### Videos

Use this to add videos.

For YouTube videos, use the embed link format:

`https://www.youtube.com/embed/VIDEO_ID`

### Gallery Images

Use this to upload photos and captions.

Categories can be things like:

- shows
- studio
- media
- flyers
- behind the scenes
- other

### Sketches / Lyrics

Use this for lyric scraps, handwritten notes, demo ideas, sketches, or anything that feels like part of the band notebook.

## Important Notes

- You do not need to touch code to update the website.
- Always click `Publish` after making a change.
- If something does not show up on the homepage, check `Homepage Featured Content`.
- If the editing dashboard asks you to log in, use the Sanity account that was invited to the project.
- The local preview link, `http://127.0.0.1:3000`, is only for testing on the developer's computer.
